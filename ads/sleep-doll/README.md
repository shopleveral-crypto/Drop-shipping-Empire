# בובת השינה – מודעת וידאו ממומנת

סרטון של 20 שניות שנערך מ-5 הקליפים המקוריים (`source/`). מבנה לפי AIDA:
הוק ("התינוק נרדם רק על הידיים? 😩") ← הכירו את בובת השינה ← ידיים רכות שעוטפות אותו ←
בובת שינה **חשמלית** ⚡ (מנגנון טפיחה בתוך כף היד) ← **היד טופחת לו על הגב — לבד!** ←
מופעלת בשלט רחוק + נטענת ב-USB ← "הידיים של אמא סוף סוף פנויות" ← כרטיס סיום עם CTA ו-14 יום החזר כספי.

## הקובץ

`output/sleep-doll_9x16_no-music.mp4`: גרסת 9:16 (רילס / טיקטוק / סטוריז), בלי מוזיקה, רק עם אפקטים
(וושים במעברים, טפיחות עדינות בקטע של היד). את המוזיקה מוסיפים מהספרייה המסחרית של טיקטוק / מטא.

## שינוי טקסטים / בנייה מחדש

כל הטקסטים והתזמונים נמצאים ב-`timeline.json` (הוקים ב-`hooks`, כתוביות ב-`captions`, כרטיס הסיום ב-`endcardOverlay`).
אילו גרסאות לייצא מוגדר ב-`exports` (`"audio": "full"` לגרסה עם המוזיקה המקורית מ-`music.py`, `"aspect": "4x5"` לפיד).
אחרי עריכה:

```
pip install numpy scipy
python3 build.py --work /tmp/ad-build
```
נדרשים ffmpeg, Node.js ו-Playwright (Chromium).
