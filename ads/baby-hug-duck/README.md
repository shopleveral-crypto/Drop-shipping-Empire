# ברווז החיבוק – מודעת וידאו ממומנת

סרטון של 19 שניות שנערך מ-5 הקליפים המקוריים (`source/`). מבנה לפי AIDA:
הוק (0–2.5 שנ') ← הצגת המוצר ← הדגמת החיבוק ← כף יד שטופחת לבד ← שלט + USB ← "הידיים של אמא סוף סוף פנויות" ← כרטיס סיום עם CTA ו-14 יום החזר כספי.

| `baby-hug-duck_hook-A_9x16_no-music.mp4` | בלי מוזיקה (רק אפקטים), כדי להוסיף סאונד טרנדי מהספרייה המסחרית של טיקטוק/מטא |

המוזיקה מקורית (מולחנת בקוד ב-`music.py`), כך שאין בעיית זכויות יוצרים.
כל החיתוכים יושבים על הביט (96 BPM). הסאונד מנורמל ל-‎-14 LUFS.

## שינוי טקסטים / בנייה מחדש

כל הטקסטים והתזמונים נמצאים ב-`timeline.json` (הוקים ב-`hooks`, כתוביות ב-`captions`, כרטיס הסיום ב-`endcardOverlay`).
אחרי עריכה:

```
pip install numpy scipy
python3 build.py --work /tmp/ad-build
```
נדרשים ffmpeg, Node.js ו-Playwright (Chromium).
